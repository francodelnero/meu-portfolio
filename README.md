# Franco Delnero — Portfolio Starter

Estrutura estática para VS Code + Live Server + GitHub Pages.

## Estrutura

- `index.html` — Home
- `css/style.css` — estilos
- `js/main.js` — interação do header e menu mobile
- `images/portfolio/` — placeholders dos thumbnails
- `projetos/` — páginas provisórias dos projetos

## Próximos passos

1. Abrir a pasta no VS Code.
2. Abrir `index.html` com Live Server.
3. Substituir os placeholders.
4. Substituir os textos e links pelos seus dados.
5. Depois publicar no repositório `SEUUSUARIO.github.io`.
